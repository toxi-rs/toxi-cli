# toxi-cli

Scaffolding, dev server, migrations, and code generation for Toxi. The
package is `toxi-cli`; the binary it installs is `toxi`.

```bash
cargo install toxi-cli
```

```bash
toxi new my-app
cd my-app
toxi dev
```

Other commands: `toxi migrate`, `toxi generate`, `toxi tinker`,
`toxi serve`, `toxi doctor`. See `toxi --help`.
